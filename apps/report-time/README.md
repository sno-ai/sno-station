# Report Time

Report Time converts a timestamp, epoch, interval, or timeout process deadline into the user’s local time.

Set `REPORT_TIME_USER_TZ` to a zone name (for example `Europe/Berlin`) to report in that zone
instead of the one in `TZ`.

The source is included here as part of Sno Station. Release archives and the supported install
path will be documented when they are published.
