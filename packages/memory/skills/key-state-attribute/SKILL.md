# Key State Attribute

## State Attribute

- Read the complete statement before you choose.
- Choose the offered slug whose meaning best describes the fact in the statement.
- Choose only one slug from the offered list.
- Return `null` when no offered slug describes the fact.
- Return `null` when you are not certain.
- Do not choose from shared words alone.
- Return only the slug or `null`. Do not add prose.
